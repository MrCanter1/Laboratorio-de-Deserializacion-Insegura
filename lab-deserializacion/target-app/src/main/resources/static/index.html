Checkout vulnerable

Restaura el carrito que quedó guardado de una compra anterior (patrón real: carrito serializado Base64 persistido del lado del cliente). POST /cart/restore deserializa sin whitelist — este es el tráfico que interceptás en Burp.

Checkout mitigado

Mismo flujo, pero contra POST /cart/restore-filtered — WhitelistObjectInputStream rechaza cualquier clase fuera de whitelist antes de instanciarla.

Verificar RCE

El exploit real corre fuera de este front (contenedor exploit, o manualmente desde Burp Repeater interceptando el checkout de arriba y reemplazando el body por un payload CommonsCollections6 generado con ysoserial). Comando ejecutado en el servidor: id, salida redirigida a /tmp/id_output.txt.
Desde terminal: docker-compose run --rm exploit http://target-app:8080 — después apretá el botón para traer la salida sin usar docker exec.
